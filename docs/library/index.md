## How to use the Library safely

The Library is not a meta list and not a replacement for the curriculum. Treat these pages as reference support. If a Library page mentions specific tools, weapons, or examples, use the principle behind them rather than assuming the item is always recommended.

If a Library page conflicts with the newer curriculum framing, follow the newer curriculum page and treat the Library page as older supporting context.
