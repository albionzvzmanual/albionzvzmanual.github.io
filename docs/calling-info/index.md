# Calling, Communication, and Information

ZvZ is not only mechanics. It is information quality.

A caller makes decisions from terrain, enemy movement, cooldowns, kill feed, scouts, minimap, roster state, and comms. Line members also need to interpret calls instead of following words blindly.

## Core rule

Better information produces better calls, better role decisions, and cleaner VOD review.

Bad information makes good players late and makes callers guess.
