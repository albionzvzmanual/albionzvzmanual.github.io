## What the ledger is for

The Formation Ledger is optional. The Albion ZvZ Manual should still be useful even if someone never opens the sheet.

Use the ledger when your group wants a practical place to:

- collect signups
- assign parties from one source of truth
- check healer, support, tank, and DPS coverage
- keep build references in one place
- run role notes, drills, and review checklists
- document comp packages without turning the manual into one comp's build sheet

## How to read the current example package

| Layer | Public meaning |
|---|---|
| Formation Ledger template | reusable signup, assignment, coverage, build, and training structure |
| Great Fire Control Formation | current filled example package, not the entire project and not a universal meta claim |
| Future packages | community-submitted or source-backed packages added only when enough reliable data exists |

This approach avoids two problems: pretending one comp is the whole manual, and replacing source-backed work with shallow meta chasing.

## How to use the ledger

1. Open the Google Sheets ledger.
2. Use **File -> Make a copy** before editing.
3. Add players on the **Signups** tab.
4. Assign party and slot from the Signups tab.
5. Let Party 1, Party 2, and dashboard views fill automatically.
6. Use coverage and role notes to fix missing healer/support/tank structure before content.

## Building future packages

A full public Formation Ledger package needs more than a weapon list. It should include role slots, builds, scaling order, healer/support requirements, caller notes, common mistakes, and enough source or testing context to avoid overclaiming.
