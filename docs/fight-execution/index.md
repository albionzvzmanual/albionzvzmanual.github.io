# Fight Execution

Fight execution is what happens between "I understand the concept" and "I did the right thing while the screen was exploding."

This section focuses on repeatable fight rules that apply across many comps.

## Practise in order

Start with [surviving first contact](first-engage-survival.md) and [keeping support in reach](spread-does-not-mean-leave.md). Then rehearse [the assigned hit](damage-lands-at-zero.md) and [the next decision](spent-cooldowns.md). Before committing, can you point to a reachable target and a covered return?
